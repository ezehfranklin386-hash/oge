FIX: Admin Login Redirect Loop

If logging in as admin bounces you back to /admin/login, the admins table is empty.
is_admin() returns false, so ProtectedRoute redirects you away.


STEP 2 - Run the grant SQL

1. Go to https://supabase.com/dashboard and select your project.
2. Click "SQL Editor" in the left sidebar.
3. Click "New query".
4. Paste the following SQL:

   insert into public.admins (user_id, email)
   select id, email from auth.users
   where lower(email) = 'admin@ginterior.ng'
   on conflict (user_id) do nothing;

5. Click "Run" (bottom right). You should see "Success".

NOTE: If the admin user does not exist yet, create it first:
Go to Authentication > Users > Add user, enter email admin@ginterior.ng,
set a password, toggle "Auto Confirm" ON, then click "Create user".


STEP 3 - Verify it worked

Run this query in the same SQL Editor:

   select * from public.admins;

You should see ONE ROW with your admin user's user_id and email.

- One row      -> admin rights granted. Log out and log back in at /admin/login.
- Zero rows    -> the auth user does not exist yet. Create it in Authentication > Users,
                  then re-run Step 2.
