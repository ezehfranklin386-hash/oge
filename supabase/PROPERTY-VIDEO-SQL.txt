G INTERIOR — PROPERTY VIDEO SUPPORT (SQL)
=========================================

WHAT THIS DOES
--------------
Adds a "video_url" column to the properties table so each property
can have one video (uploaded in the admin property form, or a pasted
YouTube/Vimeo link). Nothing else in the database changes — the media
storage bucket already allows admin uploads.

HOW TO RUN
----------
1. Go to your Supabase Dashboard → SQL Editor
2. Paste the SQL below
3. Click "Run"
4. Confirm success: you should see "Success. No rows returned"

The SQL is safe to run more than once (it checks if the column
already exists before adding it).

TO VERIFY IT WORKED
-------------------
Run this in the SQL Editor — the properties table should now list
video_url in its columns:

  select column_name, data_type
  from information_schema.columns
  where table_schema = 'public'
    and table_name = 'properties';

----- SQL STARTS HERE -----
alter table public.properties
  add column if not exists video_url text;
----- SQL ENDS HERE -----
